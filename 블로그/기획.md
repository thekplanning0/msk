# 케이의 비밀창고 — 블로그 기획

## 한 줄 소개
홈페이지, 블로그, AI 코딩, 이미지·영상 생성을 처음 해보는 케이가 직접 부딪히며 겪은 시행착오를 기록하는 블로그.

## 카테고리
| 카테고리 | 다루는 내용 |
|---|---|
| 홈페이지 만들기 | HTML·CSS부터 첫 게시까지 막혔던 곳들 |
| 블로그 만들기 | 플랫폼 고르기, 도메인, 애드센스까지 |
| AI 활용 프로그래밍 | AI에게 코드를 맡기며 배운 것들 |
| 이미지·영상 생성 | 프롬프트 실험과 실패작 모음 |

## 글마다 붙는 표시
- 막힌 시간 (예: 1시간 30분)
- 해결 여부: 해결함 / 해결 중
- 참고한 공식 문서 링크

## 글 쓰는 원칙
1. 직접 해본 것만 쓴다. 안 해본 건 안 해봤다고 적는다.
2. 막힌 시간과 해결 여부를 글마다 표시한다.
3. 참고한 공식 문서는 링크로 남긴다.

## 플랫폼 결정
**직접 만든 정적 사이트 (Astro + Cloudflare Pages + 개인 도메인)**

| 이유 | 내용 |
|---|---|
| 운영비 | 도메인값만 듦 (연 1~2만 원), 호스팅 무료 |
| 속도 | 정적 사이트라 빠름, 구글 검색 순위에 유리 |
| 보안 | 서버·DB·관리자 로그인이 없어 해킹 위험이 적음 |
| 발행 | 글 파일 하나 추가하면 1분 안에 자동 배포 |
| 글쓰기 | 웹 에디터(Decap CMS 등)를 붙이거나 Claude에게 맡김 |

## 수익화 계획
1. 글 15~20개 작성 후 애드센스 신청 (소개·문의·개인정보처리방침 페이지 필수)
2. 네이버 서치어드바이저, 구글 서치콘솔에 사이트 등록
3. RSS로 블로그 모음 사이트에 등록: 인디블로그(indieblog.net), devlog.today
